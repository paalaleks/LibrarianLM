- (decision) AD-3 candidate [ADOPTED]: MVP durable state is a filesystem-native append-only artifact ledger with immutable digest-addressed stage outputs, completion receipts, and atomically published canonical Unit Manifest snapshots. Binds FR-2, FR-7, FR-15 through FR-20, FR-24, NFR-1 through NFR-4, and NFR-10 through NFR-12. Prevents partial writes from masquerading as completed state, journal/snapshot divergence, and infrastructure coupling. Rule: lifecycle advances only after artifact validation, digest verification, and atomic receipt publication; resume replays verified receipts; all persistence is accessed through a storage port so the backing store may change later.
- (decision) AD-4 candidate [ADOPTED]: Source Unit identity is deterministically derived from the Canonical Source HTML digest, a structured DOM locator, segmentation-profile version, and segment ordinal; source-text digest is separate integrity evidence. Binds FR-4 through FR-7, FR-16 through FR-18, FR-24, FR-25, FR-31, SM-1, and SM-4. Prevents duplicate-text collisions, selector interpretation drift, fuzzy relocation, and silent source mismatch. Rule: locators are typed tuples of owned-root identity, element-child index path, text slot, and segment ordinal; CSS selectors and raw XPath are not persisted contracts; any source, locator, segmentation-version, or text-digest mismatch is a terminal deterministic finding.
- (decision) AD-5 candidate [ADOPTED]: Live generation uses deterministic wavefront execution. Binds FR-8 through FR-15, FR-24, FR-29, FR-30, NFR-3, NFR-12, and the Context Policy. Prevents runtime scheduling and provider latency from changing request context or output attribution. Rule: before a wave starts, freeze every unit's context from source neighbors plus only Machine Finals committed in earlier waves; units in the same wave never consume peer outputs; required unavailable predecessors yield blocked, while permitted absent context is encoded explicitly; wave construction, window bounds, batching, and concurrency are versioned Context Policy data.
- (decision) AD-6 candidate [ADOPTED]: Durable cross-workflow contracts are self-describing immutable JSON artifacts under one kernel-owned envelope; human-facing HTML is a projection and never machine truth. Binds FR-1, FR-2, FR-7, FR-14, FR-20 through FR-25, NFR-2 through NFR-4, and NFR-10 through NFR-11. Prevents workflow-specific serialization drift, HTML-as-state ambiguity, non-reproducible byte output, and implicit migration. Rule: every artifact declares artifact type, schema version, run identity, producing stage and attempt, input digests, payload digest, timestamps, and terminal outcome; canonical encoding is UTF-8 with LF, lexicographically sorted keys, no floats or implicit timestamps, and explicit kernel-owned schema migrations.

Rule: workflow and domain code is stdlib-first; Pydantic validates external and artifact boundaries with strict, frozen, extra-forbid models; the kernel's canonical serializer, not Pydantic defaults, determines artifact bytes.
